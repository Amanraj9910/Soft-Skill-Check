# Frontend Dependencies

This file lists additional dependencies to install after Vite creates the project.

## Core Dependencies
```bash
npm install @supabase/supabase-js axios react-router-dom
```

## UI & Styling
```bash
npm install -D tailwindcss postcss autoprefixer
npx tailwindcss init -p
```

## Media Processing
```bash
npm install @mediapipe/tasks-vision
```

## State Management & Utilities
```bash
npm install zustand date-fns lucide-react
```

## Charts & Visualization
```bash
npm install recharts
```

## Animations
```bash
npm install framer-motion
```

## Complete Installation Command
```bash
cd frontend
npm install @supabase/supabase-js axios react-router-dom zustand date-fns lucide-react recharts framer-motion @mediapipe/tasks-vision
npm install -D tailwindcss postcss autoprefixer
npx tailwindcss init -p
```
