## 🎯 **BACKEND API ENDPOINTS (20+)**

### **Users** (`/api/v1/users`)
- `GET /me` - Get current user profile
- `PUT /me` - Update profile
- `GET /stats` - User statistics

### **Assessments** (`/api/v1/assessments`)
- `POST /` - Create assessment
- `GET /` - List assessments
- `GET /{id}` - Get assessment
- `POST /{id}/complete` - Complete assessment
- `DELETE /{id}` - Cancel assessment

### **Conversation** (`/api/v1/conversation`)
- `POST /generate-response` - Generate AI response
- `POST /speech-to-text` - Convert speech
- `POST /upload-audio` - Upload audio
- `GET /audio/{filename}` - Serve audio

### **Scoring** (`/api/v1/scoring`)
- `POST /{id}/calculate` - Calculate scores
- `GET /{id}` - Get scores

### **Responses** (`/api/v1/responses`)
- `POST /` - Create response
- `POST /{id}/audio` - Upload with features
- `POST /{id}/vision` - Save vision metrics
- `GET /{id}` - Get response
